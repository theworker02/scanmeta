# scanmeta

Scan identifiers and meta tokens for idempotent workflows.

**Site:** https://theworker02.github.io/scanmeta/

## Install / run

```bash
git clone https://github.com/theworker02/scanmeta.git
cd scanmeta
node src/cli.js
node --test
```
